# Independent review before PR publication

Accepted after owner design review. Optional pre-PR review uses a fresh reviewer session, separate from the builder, because continuing the builder conversation preserves the assumptions the review should challenge. The builder implements and tests without an additional self-review stage; the reviewer reports substantive findings and may run tests but does not author fixes. This extends ADR 0004's session ownership contract to multiple role-owned sessions within one attempt.

Review enabled, harness, and model inherit independently from job to repository to global settings. New jobs default to enabled; global reviewer harness/model initially follow the effective builder choices. Effective configuration is snapshotted at attempt start, existing running attempts are not retroactively gated, and retry resolves current configuration. An unavailable reviewer configuration holds the job rather than silently falling back.

The runner permits PR publication only after PASS for the exact current commit when review is enabled. Disabled review is an explicit skip, not fabricated PASS. FIX returns findings to the existing builder session; each subsequent review uses a fresh session and isolated checkout. At most two automatic repair cycles follow the initial review. BLOCKED, invalid results, execution errors, or exhausted repairs hold for owner action. Owners may explicitly request changes or run review again, but cannot bypass PASS within a gated attempt.

Builder and reviewer share one job concurrency slot and never execute concurrently for that job. Role-specific usage contributes to job totals. Durable attempt, role, round, commit, launch and delivery identity must survive runner restart without duplicate execution or stale verdict acceptance. Dashboard and trusted CLI expose configuration, review evidence and recovery; Herdr remains unchanged. These agents run with the runner account's permissions, not in a security sandbox; report-only is an execution contract rather than an OS privilege boundary.
