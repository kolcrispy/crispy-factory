# Domain Docs

## Read before domain exploration

This repo is single-context:

- Read root `GLOSSARY.md` when present.
- Read decisions in `docs/adr/` relevant to the area being changed.
- If these are absent, proceed silently; do not create placeholders or propose them upfront. The domain-modeling skill creates them when terms or decisions are resolved.

## Vocabulary

Use glossary terms in issue titles, proposals, hypotheses, and test names. For a missing concept, reconsider invented terminology or note a genuine gap for domain-modeling.

## Decisions

Surface contradictions with an existing ADR explicitly, citing its identifier and why reopening it may be warranted.
